# happy-plate-restaurant
A fictional restaurant website created using HTML and CSS.

## About the Project

Happy Plate is a sample restaurant website designed as a web development project. The restaurant, menu, contact information, and other content presented on the website are fictional and do not represent a real business.

The project demonstrates the basic use of HTML and CSS to create and organize a simple restaurant webpage.

## Features

- Navigation menu
- Restaurant menu
- Food and drink listings
- Food gallery
- Contact information
- Responsive viewport setup
- Font Awesome icons

## Technologies Used

- HTML
- CSS
- Font Awesome 6
